# Azure Static Website Project

 

## Overview

 

This project demonstrates the deployment of a static website using Azure Blob Storage and Azure Static Website Hosting.

 

## Skills Demonstrated

 

- Azure Resource Groups

- Azure Storage Accounts
  
- Azure Blob Storage
  
- Azure Static Website Hosting
  
- ARM Templates
  
- Azure PowerShell
  
- Infrastructure as Code
  
 

## Project Workflow

 

1. Deploy Storage Account manually in Azure Portal

2. Configure Static Website Hosting

3. Upload static website content

4. Verify webpage functionality

5. Export ARM Template

6. Modify ARM Template

7. Deploy new Storage Account using Azure PowerShell

8. Upload second website content

9. Verify second webpage functionality
